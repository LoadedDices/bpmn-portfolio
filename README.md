# Портфолио бизнес-аналитика: BPMN

Здесь я собираю процессы, которые моделирую во время учёбы на курсе Яндекса. Бизнес аналитик.

Схемы рисую в нотации BPMN 2.0. 

## Кейсы

### 01\. Сытый зайка — доставка продуктов

Обработка заказа, когда части товаров нет на складе. В версии «as is» оператор звонит покупателю и согласовывает замены вручную. В версии «to be» звонок заменён на push в приложении с ожиданием ответа и таймером на 10 минут, ручной шаг оператора уходит из сценария.

## Как читать файлы
